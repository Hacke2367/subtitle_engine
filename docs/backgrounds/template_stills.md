# Background templates: code-drawn stills and their ratings

**Status:** stills for the H-038 ideas, drawn by code (no AI images), 2026-09-30. Each type's
ideas were drawn as two stills on `khidki_s2_em` (7.5 s: the marked word "Dil"; 13.7 s: the
last word). A critic agent then rated each from an artist's and a scrolling viewer's side, and
against the owner's rules (H-032), 0-10. One fix round followed, and the critic rechecked. The
owner picks from here; nothing is final yet.

Files (gitignored, review only): `songs/_review/backgrounds/templates/<type>/`: `00_<type>.png`
is the sheet, `draw.py` draws it; every agent's full notes are in `_results.json`.
